# aislog-wordpress

**aislog-wordpress** is a collection of
[WordPress](https://wordpress.org/)
[Postie](https://wordpress.org/plugins/postie/)
plugins which together render a mail message of the type generated by
[aislog-uploader](https://github.com/pdjr-signalk-plugins/aislog/tree/main/src/aislog-uploader).
into meaningful blog post.

The mail processing model is a simple one and begins with a Postie
'post-before' filter which processes an incoming email by saving each
attachment into the WordPress media archive and inserting a WordPress
shortcode into the post content which will trigger rendering of each
attachment as the post is displayed.

The remaining scripts in the collection are simply WordPress shortcode
handlers for each of the different attachment types.
Note that there is a name-based mapping between an attachment filename
extension, the name of its associated shortcode and (by convention) the
name of the script implementing the shortcode.

Thus, an attachment called '20260102.ext' will be represented in its
containing post by a shortcode of the form '[ext url='...']'. The
implemention the 'ext' shortcode handler will be defined in the
`aislog-ext-shortcode.php` script.
Adding support for a novel attachment type trivially requires just the
coding of a new shortcode handler script.

## Installation

The various **aislog-wordpress** scripts implement the final stages of
the aislog publishing process and can be installed at any time.
Obviously, the earlier stages of the publishing process must be in
place and working before this final stage can operate as intended and,
additionally, the host WordPress installation may require some
configuration.

1. If necessary, install the WordPress Postie plugin and configure it
   to retrieve and process messages from the dedicated email account to
   which 'aislog-uploader' sends its daily ais log.
   Configure Postie so that it scans the email account once every hour.

2. If necessary, install a WordPress extension that allows definition
   of new MIME types (I use the "Add MIME Types" plugin) and configure
   support for any non-standard file extensions.
   At the very least you will need to add the 'ais' extension and
   declare it to be of type 'text/plain'.

3. Login to your WordPress site host, and download the 'aislog' git
   repository.

   ```bash
   cd
   git clone https://github.com/pdjr-signalk-plugins/aislog
   ```

   Then copy the scripts from the **aislog-wordpress** collection onto
   your WordPress installation's 'must-use' plugins directory (you may
   need to adjust the location of this target folder and the owner of
   WordPress files in the following example).

   ```bash
   $> sudo cp aislog/aislog-wordpress/*.php /srv/www/wordpress/wp-content/mu-plugins/
   $> sudo chown www-data:www-data /srv/www/wordpress/wp-content/mu-plugins/aislog-*.php
   $> sudo chmod 755 /srv/www/wordpress/wp-content/mu-plugins/aislog-*.php
   ```

   And finally delete the no-longer-required git repository.

   ```bash
   rm -r aislog
   ```
